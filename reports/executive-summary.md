# Executive Summary

## Overview

The Enterprise SOC Lab demonstrates centralized security monitoring using Splunk Enterprise.

Windows event logs are collected from Active Directory and Windows endpoints through the Splunk Universal Forwarder.

The environment supports:

- Centralized logging
- Detection Engineering
- Incident Investigation
- Dashboard Monitoring
- Security Reporting

---

## Key Achievements

- Active Directory deployed
- Windows Event Log collection configured
- Splunk Enterprise deployed
- Security dashboard created
- Multiple detection rules implemented
- Incident investigation workflow documented
