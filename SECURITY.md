# Security Policy

## Supported Versions

This repository is intended for educational and portfolio purposes.

---

## Reporting Security Issues

If you identify a security issue in this repository, please open a GitHub Issue with a description of the problem.

Please do not include sensitive credentials, private keys, or production data in reports.

---

## Responsible Disclosure

This project is designed for use in isolated lab environments only.

Do not use these configurations or detection rules against systems without proper authorization.
