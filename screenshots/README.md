# Enterprise SOC Lab Screenshots

## Overview

This directory contains screenshots captured from the **Enterprise SOC Lab**, demonstrating the deployment, configuration, monitoring, and detection capabilities implemented using **Splunk Enterprise**, **Windows Server**, **Active Directory**, and **Splunk Universal Forwarder**.

The screenshots provide visual evidence of the complete Security Operations Center (SOC) workflow, from Windows event generation to log collection, centralized monitoring, detection engineering, and incident investigation.

---

# Screenshot Gallery

## 01. Enterprise SOC Dashboard

**File:** `01-enterprise-soc-dashboard.png`

Displays the complete Enterprise SOC Dashboard developed in Splunk Enterprise. The dashboard provides centralized visibility into Windows security events through multiple visualization panels, enabling analysts to monitor authentication activity, analyze security events, and investigate suspicious behavior.
