# Enterprise SOC Dashboard

This directory contains documentation for the Splunk dashboard developed during the Enterprise SOC Lab.

## Dashboard Objectives

The dashboard provides centralized visibility into Windows security events and supports Security Operations Center (SOC) monitoring.

## Features

- Authentication Monitoring
- Windows Event Monitoring
- Security Event Timeline
- Host Activity
- Threat Summary
- Recent Security Events

## Dashboard Components

- Authentication Statistics
- Windows Event Distribution
- Investigation Timeline
- Top Hosts
- Event Types
- Recent Security Events
