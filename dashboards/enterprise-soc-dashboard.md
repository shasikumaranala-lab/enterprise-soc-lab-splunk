# Enterprise SOC Dashboard

## Overview

The Enterprise SOC Dashboard was created in Splunk Enterprise to provide a centralized view of Windows security events collected from the lab environment.

The dashboard helps analysts monitor authentication activity, investigate suspicious events, and identify trends across monitored systems.

---

## Dashboard Goals

- Centralized security monitoring
- Authentication visibility
- Event analysis
- Threat detection
- Incident investigation

---

## Data Sources

| Source | Description |
|---------|-------------|
| Windows System Logs | Operating system events |
| Windows Security Logs | Authentication and security events |
| Windows Application Logs | Application events |

---

## Dashboard Panels

1. Authentication Statistics
2. Windows Event Distribution
3. Investigation Timeline
4. Top Hosts
5. Event Types
6. Recent Security Events

---

## Benefits

- Faster event investigation
- Improved visibility
- Centralized monitoring
- Quick identification of suspicious activity
